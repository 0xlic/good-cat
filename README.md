# good-cat

**统一流量规则，优选订阅节点，让 Agent 使用更丝滑。**

good-cat 让 Agent 帮你管理 FlClash：为 ChatGPT、Claude 等服务挑选合适的节点国家，统一分流规则，减少手动配置。

## 怎么用

先安装 FlClash 并导入订阅。支持 macOS 和 Windows x64。

复制下面这段话发送给你的 Agent：

```text
请安装并使用 good-cat：https://github.com/0xlic/good-cat 帮我优化代理网络。
```

下载工具、测速、分析结果、生成和安装配置，都交给 Agent。**不用手动下载文件或输入命令**，你只需查看建议，在关键步骤回复确认。Agent 会先确认 FlClash 的实际安装位置，支持自定义目录和便携版。

所有由 good-cat 创建的内容都留在当前项目目录，不进行全局安装：

```text
.agents/skills/good-cat/   项目本地 Skill
.good-cat/bin/             CLI
.good-cat/workspaces/      测速与生成文件
.good-cat/tmp/             临时文件
.good-cat/backups/         配置备份
.good-cat/state/           锁和恢复日志
```

不再使用用户缓存、系统临时目录或 FlClash 数据目录保存这些工具文件。完成后删除 `.good-cat/` 和项目本地 Skill 即可清理；FlClash 自身的配置、数据库和订阅仍保存在 FlClash 数据目录。

## 它会做什么

- 默认进行三轮测速，优选延迟低于 600 ms 的节点。
- 现有国家关键词仅作参考；未匹配的明确地域由 Agent 动态补充规则，不因国家小众而漏选。
- ChatGPT、Claude 分别按实测结果优选最多三个国家，不预设国家；优先选择低于 600 ms 的合格节点更多的地区，数量相同时再比较中位延迟。单节点地区作为备选，不足三个按实际数量。ChatGPT、Claude 在排名前排除香港、澳门节点；通用 Proxy 分组不排除。均为自动测速分组。
- 你可以在 FlClash 中用原生“首选”固定 Claude 的具体节点，再去检查出口 IP；需要锁定某个国家时，让 Agent 缩减国家范围即可。
- 统一分流：中国大陆、微软、苹果和本地地址直连，其余流量按分组代理。
- 首次使用只给出一份默认方案，回复“继续”即可；已有方案会先读取再按你的要求局部调整。
- Agent 根据当前订阅名称为脚本取简短名字，无需你单独确认命名。
- 经你确认后，备份原配置、安装脚本并关联当前订阅。
- 可按需调整当前 good-cat-xxx 脚本，保护已有用户脚本。

## 使用提醒

- 配置过程中可能短暂断网，Agent 会提前提示并等待确认。
- **Claude 频繁切换 IP，尤其跨国家切换，可能触发风控，存在受限或封号风险。**请先自行检查 IP 信誉/纯净度，再按需要求缩减到一个国家，尽量固定可信节点。
- 测速不等于 IP 信誉检测，也不保证服务解锁或账号安全。

# good-cat

**统一流量规则，优选订阅节点，让 Agent 使用更丝滑。**

good-cat 让 Agent 帮你管理 FlClash：为 ChatGPT、Claude 等服务挑选合适的节点国家，统一分流规则，减少手动配置。

## 怎么用

先安装 FlClash 并导入订阅。支持 macOS 和 Windows x64。

复制下面这段话发送给你的 Agent：

```text
请安装并使用 good-cat：https://github.com/0xlic/good-cat 帮我优化代理网络。
```

下载工具、测速、分析结果、生成和安装配置，都交给 Agent。**不用手动下载文件或输入命令**，你只需查看建议，在关键步骤回复确认。

## 它会做什么

- 默认进行三轮测速，优选延迟低于 600 ms 的节点。
- ChatGPT、Claude 默认都保留台湾、新加坡、日本三个国家；ChatGPT 自动选优，Claude 手动切换国家和节点。
- 统一分流：中国大陆、微软、苹果和本地地址直连，其余流量按分组代理。
- Agent 根据当前订阅名称为脚本取简短名字，无需你单独确认命名。
- 经你确认后，备份原配置、安装脚本并关联当前订阅。
- 可按需调整当前 good-cat-xxx 脚本，保护已有用户脚本。

## 使用提醒

- 配置过程中可能短暂断网，Agent 会提前提示并等待确认。
- **Claude 频繁切换 IP，尤其跨国家切换，可能触发风控，存在受限或封号风险。**请先自行检查 IP 信誉/纯净度，再按需要求缩减到一个国家，尽量固定可信节点。
- 测速不等于 IP 信誉检测，也不保证服务解锁或账号安全。
